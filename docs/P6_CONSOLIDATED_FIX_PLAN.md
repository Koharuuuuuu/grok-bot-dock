## 执行总规则

1. 先核对当前 master 的代码和部署镜像版本、前端静态资源版本、缓存与运行环境，避免“代码已改、部署未更新”误判；记录 commit、镜像 digest、运行版本及复现步骤。没有生产环境权限时注明未验证，不得声称线上已修好。
2. 每个问题执行「复现 → 根因 → 最小修复 → 自动化测试 → 真实浏览器验证 → 截图/日志证据 → 勾选」。已修复的功能做回归，不要推倒重做。
3. 用 Playwright 或等效真实浏览器，在 1440/1280 桌面及 320/375/390/430/768px 移动宽度验证。至少两条不同 Bot 报告、长 Markdown、表格、代码、历史报告及搜索跳转。
4. 任何状态持久化需求必须明确作用域：阅读偏好保存在浏览器 localStorage；Bot 自定义名称持久化到 SQLite；会话由安全服务端认证与 Cookie 维护。
5. 避免新增 Redis、PostgreSQL、独立前端容器、重量级 UI 组件库或不必要依赖。不要改仓库可见性，不要泄露 Token。
6. 每项按验收结果勾选，最终生成 `docs/P6_ACCEPTANCE_REPORT.md`，附根因、修复路径、验证命令、截图位置、CI run、镜像 digest、未解决问题。只有用户可见行为达标才可标记完成。

## P0-01 登录后刷新退出
- [ ] 复现登录后 F5 / Ctrl+R / 新标签页被登出，核查 Cookie、SPA 初始化、认证状态恢复、跨标签、代理、SameSite/Secure、401、前后端版本。
- [ ] 同一浏览器会话内只需登录一次，刷新、切换页面、新标签页不丢登录；主动退出立即撤销会话，刷新与其他标签均不得继续访问。
- [ ] 保持 HttpOnly/Secure(HTTPS)/SameSite 合理设置，勿把 Bearer 密钥放 localStorage；注意浏览器「恢复上次会话」可能恢复 session cookie，不能虚称可靠侦测关闭浏览器。
- [ ] 测试：登录→刷新 3 次→新标签→退出→两标签失效；过期与服务重启行为明确记录。

- [ ] 多次打开/关闭、切换历史与长文档时无明显抖动；关闭后主页面滚动位置不变。

- [ ] 最大化模式正文**保持清晰**，不继承 blur/backdrop-filter；此项用户反馈已修好，仅做回归，禁止回退。

## P0-05 最大化阅读模式持久化
- [ ] 普通/最大化状态作为**跨 Bot 全局阅读偏好**保存在版本化 localStorage 键；默认普通，损坏值回退普通。
- [ ] 最大化→关闭→打开另一 Bot/报告直接最大化（不能先普通再闪变）；刷新、重新登录、关闭浏览器重开仍记住。
- [ ] 主动还原后，下一个报告普通模式；切换历史/搜索结果不重置；移动端因窄屏强制全屏不能污染桌面偏好。
- [ ] 与字号设置相互独立，不丢失当前报告、阅读位置。

## P0-06 Markdown 字号缩放与持久化
- [ ] 在详情顶部日期与最大化按钮之间添加缩小、字号显示、放大、重置；默认 16px，范围 12–24px，步长 1px。
- [ ] 仅缩放 Markdown 阅读区正文、标题、表格、代码等排版，不能缩放工具栏、侧栏或整页；移动端采用紧凑控件。
- [ ] 版本化 localStorage 持久化，刷新、换 Bot、重新登录、重开浏览器后仍保持；非法值回退 16px；普通/最大化共享。
- [ ] 实测边界值、重置、长文档换行、移动端横向溢出。

## P0-07 复制 AI 推送指令：真正零配置
- [ ] 服务 URL 默认自动取当前访问站点 origin 与正确 API base path，不再显示 YOUR_DOMAIN；允许高级覆盖。提示公网 HTTPS 可达性，避免 localhost 无法由外部 Agent 调用。
- [ ] **移除稳定 Bot ID 必填输入**，由 Agent 使用可获取的稳定任务 ID 或稳定任务名称派生并在每次执行复用；无法取得稳定身份时明确提示配置/拒绝，禁止随机 ID 或每天生成新 Bot。
- [ ] source / bot_name 尽量自动识别；source 无法识别允许空白并由服务端归类 unknown；确保后端校验、迁移兼容、API 文档、前端提示词一致，不能只改表单。若平台能力不足不得假装推送成功。
- [ ] 提示词清晰指示：仅最终正式 Markdown 报告完成后推送一次；测试文件、草稿、日志、中间结果、失败任务不推送；保留原始 Markdown、链接、标题、表格，真实 RFC3339 执行时间、稳定 external_id、失败重试与成功判断。
- [ ] 复制指令包含准确 POST /api/v1/reports、Content-Type、JSON 示例、必要的安全认证说明；不得复制真实 Token 到提示词/日志；若服务端要求 Bearer Token，必须明确 Agent 端安全配置，不能宣传无鉴权。
- [ ] 界面默认只需一个复制按钮，必要设置放高级选项；桌面/移动端剪贴板可用。用两次不同日期同一任务推送验证不产生重复 Bot，旧 Bot 身份保持兼容。
