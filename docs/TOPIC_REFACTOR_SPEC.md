# Agent 驱动的主题空间重构

本次授权与验收基线：2026-10-17 对话确认的主题空间设计；现有 REST、MCP、会话、OAuth、分享及旧报告兼容。

## 产品约定

- 主题是主入口，Agent 是执行者。关注、有更新、全部主题、已归档为导航；未分组只作为筛选条件。
- 首次正式推送自动建立主题，后续稳定任务沿用主题；显式 topic_id 可让多个任务/Agent 贡献同一主题。不通过相似名称自动合并。
- 旧数据库按稳定 Bot 身份迁移为主题，不删除或改写原始报告、全文索引、分享或 OAuth 数据。
- 支持主题命名、分组、关注、置顶、批量整理、逐篇已读、主题与内容搜索、游标分页。
- 停止跟踪先进入 stop_requested；每个贡献任务用请求版本确认已停止后才归档。也允许所有者明确声明已在外部停止并记录原因。恢复保留主题及历史，不声称已重启外部调度。
- archived 拒绝新报告，stop_requested 接受已在途的既有任务报告；重复重试仍返回原报告。旧停止请求的确认不能结束新任务周期。
- 复制一条接入文案，包含 MCP 地址、能力发现、安全授权、主题身份、幂等与停止协议。明确平台能力不足时需人工配置，不复制管理员密钥。
- 现有分享、来源检索、通知、REST 推送、OAuth 管理继续可用。前端的所有正式内容来自真实接口，不包含演示数据。

## 验证要求

数据库迁移与重启；REST/MCP 发布、重试和跨 Agent 关联；停止请求/版本/确认/恢复；权限与无效输入；分页与已读；前端交互、搜索、分享、接入复制、浅深色、窄屏；完整 Go/前端测试和构建；两轴代码审查；记录实际证据及未验收项。
