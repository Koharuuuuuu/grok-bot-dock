# P7 · MCP 通用接入界面 UI/UX 优化与执行清单

> 2026-10-10 用户确认。**本文件是交给 Codex 的待执行任务，不代表功能已实现。** 目标分支 master。与 [P7 MCP 独立服务定位纠偏](./P7_MCP_PRODUCT_POSITIONING_CORRECTION.md) 配套执行。Bot Dock 是独立 MCP Server；Codex 是开发工具，不是产品必需组件。任何兼容自定义远程 MCP 的 Agent 都可在授权后调用，具体第三方平台是否支持必须实测。

## 一、产品信息架构与文案

- [x] 工作台主入口和页面标题为中立的「MCP 接入」「MCP 服务接入」。
- [x] 页面说明 MCP 服务适用于支持远程 Streamable HTTP MCP 的 Agent，不承诺所有 AI 客户端都能连接。
- [x] MCP 路径与 REST API 路径在入口和 REST 推送指令中明确区分；原 REST 入口保留。
- [x] Codex CLI 示例位于折叠的可选区域，默认不显示环境变量或 Codex 专属连接说明。

## 二、推荐页面结构（按现有视觉系统落地，不推倒重做）

### 区块 A：服务连接信息（首屏最重要）
- [x] 默认从当前页面地址推导 `/mcp`；允许反向代理覆盖并保存到当前浏览器。私有地址显示可达性提示。
- [x] 从服务端能力显示 Streamable HTTP 和 Bearer；不显示连接状态或伪造在线状态。
- [x] URL 与通用说明分开复制；对话框和实际剪贴板内容反馈一致且不含密钥值。
- [x] 通用说明复制包含协议、URL、Bearer 头、工具列表、参数示例与接入步骤，不伪装成统一客户端配置文件。

### 区块 B：认证与 Token 安全
- [x] 明确说明 `ACCESS_TOKEN` 是共享密钥，仅适用于单用户受信任接入，没有独立 Token、授权或撤销能力。
- [x] 实际测试密钥未出现在 UI、剪贴板、localStorage、URL、文档或截图中。
- [x] `BOLT_DOCK_TOKEN` 只出现在折叠 Codex CLI 示例，并解释为该客户端的本地环境变量名。
- [x] 不提供虚假的 Agent Token 管理入口；另立安全设计要求记录在产品边界中。

### 区块 C：工具能力
- [x] 工具清单由已鉴权的后端能力接口返回，与真实 MCP 注册项共享定义。
- [x] 显示每个工具的用途、字段、读写属性和无凭据参数示例；发布参数含稳定 Bot 身份与 external_id 幂等，搜索说明分页上限。
- [x] 说明发现/调用工具不代表客户端自动推送。

### 区块 D：接入步骤与可选客户端示例
- [x] 页面和复制说明提供三步接入流程。
- [x] Codex CLI 示例折叠显示为已验证的具体 CLI 版本；其他平台清楚标注需要检查具体客户端能力，未声称 Grok/Claude 全面兼容。
- [x] 提供 401、404、Streamable HTTP/stdio 差异及跨源 Origin 排查说明；不含秘密值。

## 三、视觉与交互约束
- [x] 沿用现有视觉系统与模式切换，未重构首页。
- [x] Playwright 实测桌面 1440/1280 和移动 430/390/375/320px 无横向溢出，浅色/深色外观均检查。
- [x] 对话框支持 Esc、焦点循环和关闭后焦点返回；REST 入口仍可打开。

- [x] UI 提示统一简体中文，能力加载/失败状态有明确说明。

## 五、Codex 交付边界

1. 本 UI 任务与 P7 MCP 后端任务协同；优先实现**通用服务入口**，不要求用户先安装任何特定 AI 客户端。
2. 保留 `/mcp`、REST API、数据库结构、GHCR 镜像名、Docker 单容器、`/data` 以及已完成 P6 功能。
3. 通过仓库规定的 PR/CI 流程合并 master；若需真实外部平台账号才能验证，记录阻塞，不得编造测试结果。
4. 最终 UI 必须让首次使用者看懂：**「这是我的 MCP 服务地址；任何支持该协议并获得授权的 AI 客户端都可以连接并推送报告」**。
