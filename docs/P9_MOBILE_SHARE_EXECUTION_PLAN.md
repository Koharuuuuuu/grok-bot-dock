# P9 · 移动端适配专项修复 + 报告限时分享（Codex 执行计划）

> 2026-10-12 用户需求。状态：**待开发、待验证**。本文是新增任务，不代表功能已经实现。仓库 `Nyakooo/grok-bot-dock`，默认分支 `master`。主 Agent 负责集成，子 Agent 可并行审计移动端/设计分享数据模型/测试，但不得同时修改共享核心文件。
>
> 需求原文要点：移动端主题切换、信源选择和 select 看不清内容且控件堆叠；支持从报告内容生成随机 hash 分享链接，按小时/天选择有效期，**最短 1 小时、最长 7 天**，到期自动失效并清理 hash；链接打开独立分享页，可阅读报告详情。

## 0. 不可变约束与交付原则

- 保留 P7 MCP、P8 OAuth（默认开关与旧 Bearer）、REST 推送、登录、SSE、SQLite/FTS、Bot 稳定身份、`external_id` 幂等、既有报告与主题设置。
- Go + Vue 3 + SQLite + 单 Docker 镜像，数据仍在 `/data`；不得为分享引入 Redis、独立服务、外部对象存储或短链第三方。
- **分享仅针对单条报告**，不可访问后台列表、历史、其他 Bot、搜索、MCP 或管理 API；公开访问不需要登录，但必须仅凭不可猜测的分享凭据读取被授权的报告。
- 链接过期或撤销后**立即拒绝访问**，后台清理 hash 记录是另一个异步动作；不可把“删除记录”作为唯一失效机制。已访问/缓存/截图/转存的内容不能远程销毁，UI 不得误导。
- 分享链接的“hash”指安全随机生成的**不透明令牌**，不是报告内容 SHA/MD5，也不是可推算 ID；存储只保存令牌摘要，不保存原始令牌。
- 不自动部署生产，不使用真实生产报告进行测试，不在日志/CI/文档中出现真实分享凭据。
- 本次用户已明确授权**执行计划文档 push 到 master**；不代表授权 Codex 后续自动推送/合并实现代码或部署生产，后续遵守用户最新授权指令。

## Phase 2：限时分享的产品契约

### 用户流程

1. 已登录用户打开任意报告详情，点击「分享」；打开轻量弹窗/底部抽屉。
2. 选择有效期：按**小时**或**天**。小时允许整数 `1–168`，天允许整数 `1–7`；默认 **1 天**。前端实时显示明确到期日期/时间及用户时区；后端按创建时 UTC 计算绝对到期时间。
3. 点击「创建分享链接」，服务端生成随机令牌，返回完整 HTTPS 链接、到期时间；提供复制成功/失败反馈，明确“拥有链接的人可在有效期内无需登录阅读此条报告”。
4. 打开链接进入**独立公开分享页**（不显示主工作台导航、Bot 列表、历史、管理、OAuth/MCP 入口），可阅读该条报告的标题、来源/作者（按已有非敏感展示字段）、执行时间、Markdown 正文；允许在此报告内查看完整详情和复制分享页 URL，不提供越权跳转。
5. 到期后直接展示统一的“分享链接已过期或不可用”页面；主动撤销亦相同响应，不暴露是否存在对应报告。分享页不提供续期或登录管理入口。
6. 已登录用户可在该报告的分享管理区域查看已有有效分享记录（**仅元数据**：创建时间、到期时间、状态）并逐条撤销；原始分享 URL 仅创建时展示，后续不能从数据库恢复。重复创建生成不同令牌；每份报告最多 **20 个有效分享**（可在 Phase 0 依据产品/资源约束调整并记录理由）。

### 关键产品决策

- [ ] 分享对象为**单份报告当前内容的实时引用**，不是复制静态快照：原报告被删除后分享立即失效；报告内容若将来支持编辑，分享页显示最新内容。若用户希望历史不可变快照，另立需求，不在本期混入。
- [ ] 最小有效期 1h，最大 168h，小时/天为**创建时长**而不是自然日边界；用户不能绕过 UI 提交 0、负数、小数、超 168h、NaN 或任意过长 TTL。
- [ ] 分享页面默认不提供搜索引擎索引能力：`X-Robots-Tag: noindex, nofollow, noarchive`，分享页 HTML meta robots；不承诺搜索引擎完全遵守。
- [ ] 分享内容视为持链接公开：如报告中有敏感信息，创建前明确提醒。不得将 OAuth Token、Bearer Token、管理员会话、内部路径等自动附加到分享链接。
- [ ] 不提供“永不过期”；到期不可恢复原 hash，可创建新的分享链接。

## Phase 3：后端接口与数据库（先契约后代码）

### 建议 API（实际按现有路由风格调整，记录最终契约）

| 方法与路径 | 鉴权 | 语义 |
| --- | --- | --- |
| `POST /api/v1/reports/{id}/shares` | 已登录管理员会话 | 创建分享，Body `{"ttl_unit":"hour"\|"day","ttl_value":1..168 或 1..7}`；返回 `share_url`、`expires_at`、`share_id` |
| `GET /api/v1/reports/{id}/shares` | 已登录管理员会话 | 仅列出该报告分享元数据，不返回原始 token |
| `DELETE /api/v1/reports/{id}/shares/{share_id}` | 已登录管理员会话 | 撤销，幂等语义明确 |
| `GET /api/v1/public/shares/{token}` | 无需登录 | 返回**单条报告白名单字段**；无效、过期、撤销统一 404 或 410（避免枚举差异） |
| `GET /share/{token}` | 无需登录 | 独立分享页 SPA 路由，刷新/直达可用 |

- [ ] 令牌用密码学安全随机源至少 32 bytes（如 `crypto/rand`），base64url 无填充编码；数据库仅存 `SHA-256(token)` 的摘要，绝不存明文 URL。分享 ID 为内部管理标识，与公开 token 分离。
- [ ] 新增 SQLite `report_shares` 表（示意）：`id`、`report_id` 外键、`token_hash` 唯一、`created_at`、`expires_at`、`revoked_at`、可选 `created_by`（本期单所有者）。按 report_id / expires_at 建索引，外键与删除行为明确；采用 additive migration，旧数据不变。
- [ ] 读取时必须在**每次请求**以服务端 UTC 检查 `expires_at > now` 且未撤销，报告仍存在；返回字段白名单，不调用已有要求管理员权限的列表接口后再粗暴剥离。
- [ ] 原始分享 token 不进入访问日志、错误栈、分析埋点、Referer、外部图片请求 URL、前端持久存储。特别注意 **URL path 含 token**：HTTP logger 必须对 `/share/*`、`/api/v1/public/shares/*` 路径脱敏；反向代理访问日志亦需部署说明。
- [ ] 响应设置 `Cache-Control: no-store`、`Referrer-Policy: no-referrer`、`X-Content-Type-Options: nosniff`、合适 CSP；独立分享页避免加载未经审计的第三方脚本/字体/追踪资源。Markdown 图片、外链可能泄露访问者 IP 或分享 URL 的 Referer，明确安全处理（例如图片代理/禁用远程图片/严格 referrer 策略，按现有渲染能力选最安全的最小改动）。
- [ ] 公共接口限流、长度/字符格式校验、固定响应策略，避免暴力枚举和报告存在性探测；对管理员创建/列出/撤销接口做 CSRF/Origin/session 校验；**MCP OAuth token 和 Legacy REST Bearer 不得因此获得分享管理权限**。
- [ ] TTL 只由服务端计算，时间回拨/时区/DST 不影响绝对过期；重复撤销与并发到期读取行为明确。分享令牌不可从 `report_id`、`external_id`、Bot ID、正文哈希推导。
- [ ] **自动清理**：过期立即逻辑失效；后台轻量定时清理过期/撤销的 `report_shares` 记录（建议每小时一次、批量限量、SQLite 事务短小、启动时补清理），不清除报告本体。清理失败不影响过期安全；容器重启后恢复清理。可保留必要的不含令牌的安全审计摘要，明确保留策略。
- [ ] 反向代理 /share/*、/api/v1/public/shares/* 可达；SPA fallback 不把 public API 404 错误吞掉。OAuth /mcp、/oauth/* 与旧 REST 认证不受影响。

- [ ] 复用现有安全 Markdown 渲染与阅读排版组件，但不继承依赖登录态的 API 调用；支持表格、代码、引用、链接、长文章阅读，避免 XSS、DOM 注入和危险链接。
- [ ] 支持亮/暗主题或系统主题，移动端 320px 起无横向溢出；独立阅读页不依赖用户原有登录状态；加载、失败、过期、撤销、报告删除、网络断开均有明确状态。
- [ ] 页面公开后不能依赖“只隐藏按钮”保护数据；接口级严格限制可见字段。
- [ ] 分享弹窗桌面和移动端都可操作；有效期输入有明确单位、边界、错误提示和到期预览，复制链接不会意外关闭弹窗；关闭后再次打开不假装能恢复原 token。
- [ ] 分享页对长期保持打开的场景：到期后重新请求必拒绝；可在前端按 expires_at 自动切换过期状态/清除显示（不构成撤销已被用户复制内容的承诺），页面恢复可见时重新校验。
